# POMODORO TIMER PROJECT
This was a small project I developed as a personal challenge, practice and a gift for my boyfriend.

## PROPOSAL
My initial idea was to develop a Pomodoro timer that would help my boyfriend study. Regarding the features, I wanted the user to not only have access to the timer, but also be able to customize the work and break times. The program has a retro aesthetic inspired by Windows 95. This design choice was made because we both like the look of older versions of Windows.
